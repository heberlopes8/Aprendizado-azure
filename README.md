Resumo de Aprendizado – Plataforma Azure e Desenvolvimento Web com Python

Durante a realização do curso, adquiri competências técnicas fundamentais no ambiente de computação em nuvem da Microsoft Azure. Entre os principais aprendizados, destaco a configuração de serviços de armazenamento (storage), incluindo a criação e gestão de contêineres em contas de armazenamento.

Também aprendi a configurar o SQL Server no Azure e a realizar a integração com aplicações desenvolvidas em Python, compreendendo de forma prática os processos de conexão entre banco de dados e código-fonte.

Como parte das atividades práticas, desenvolvi meu primeiro projeto de E-commerce, o que me permitiu compreender os princípios da criação e estruturação de páginas comerciais. Além disso, explorei o uso da biblioteca Streamlit, uma ferramenta eficiente para o desenvolvimento de interfaces web interativas, especialmente úteis na criação de sites e dashboards dinâmicos.

Essas experiências ampliaram minha visão sobre soluções em nuvem, integração de dados e desenvolvimento de aplicações voltadas ao ambiente digital.
